    06How It Works

    Pipeline, end to end

    01
    apps.csv
    100 apps, one row each: name, category, hint URL.
    02
    Firecrawl retrieve + cache
    Search + scrape real docs pages once; cached to disk so re-runs cost nothing.
    03
    LLM extract
    Local qwen2.5:7b and Gemini extract structured fields, grounded to the scraped page only.
    04
    Reconcile + verify
    Merge to one best-answer row; check against a 20-app hand-labeled sample.

    A human was needed in two places this pipeline doesn't automate: writing the 20-app ground-truth sample, and building this page.
